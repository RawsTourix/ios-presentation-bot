# iOS Presentation Bot

Telegram-бот для интерактивного опроса аудитории и отображения результатов в реальном времени во время выступления **«Архитектура iOS»** по дисциплине «Операционные системы».

**Дата выступления:** 21 октября 2026 года.  
**Статус:** первый этап реализации в ветке `feat/polling-mvp` — Telegram-бот и SQLite. Web API, диаграмма, публичный HTTPS и развёртывание на VPS пока не реализованы.

## Идея

На первом слайде презентации показывается QR-код со ссылкой на Telegram-бота. Участники выбирают ОС основного смартфона: **iOS**, **Android** или **другая**. На экране преподавателя/проектора открыта веб-страница с двумя анимированными столбцами iOS и Android; голоса за другие системы учитываются отдельно. Числа и проценты обновляются без ручного обновления страницы. Автор выступления управляет началом и завершением голосования через Telegram.

Результаты относятся **только к проголосовавшей аудитории**, не к рынку смартфонов в целом.

## Планируемый стек

- Python, **aiogram 3** — Telegram-бот.
- **FastAPI + Uvicorn** — HTTP API и SSE.
- **SQLite (WAL)** — сессии и голоса.
- HTML/CSS/JavaScript + **Chart.js** — экран результатов.
- Ubuntu VPS, systemd, HTTPS через reverse proxy — размещение.

Точный состав зависимостей и версии фиксируются при реализации.

## Объём первой версии (MVP)

1. Один вопрос про ОС основного смартфона.
2. Один голос на Telegram-аккаунт в пределах сессии, возможность изменить ответ до закрытия.
3. Авторизованный администратор начинает и завершает опрос; несколько тестовых раундов не смешивают данные.
4. Публичный экран агрегированных результатов с автоматическим обновлением и финальным состоянием.
5. Данные переживают перезапуск процессов.

## Разработка — этап 1

Добавлены `ios_poll/` (бот и SQLite), `tests/` и автоматические проверки GitHub Actions.

Локальный запуск (Python 3.11+):

```bash
python -m venv .venv
# Активируйте окружение, затем:
python -m pip install -e '.[dev]'
# Установите BOT_TOKEN, ADMIN_TELEGRAM_ID и DATABASE_PATH в окружении.
python -m ios_poll.bot
```

На Windows в PowerShell задать переменные можно так: `$env:BOT_TOKEN="..."`. Значения из `.env.example` — только шаблоны, загрузка `.env` автоматически не производится.

**Проверки:** `python -m pytest -q` и `python -m compileall -q ios_poll tests`.

Известные ограничения первой версии: требуется действительный токен и настройка Telegram; реальный запуск с Telegram пока не подтверждён; рассылка итогов best-effort, прерванная после постановки в очередь отправка требует отдельного механизма восстановления; FastAPI и экран результатов — следующий этап. Токены, IP-адреса, идентификаторы пользователей и другие секреты в Git не добавляются.
